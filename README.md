# ♟️ لعبة الداما الاحترافية (Professional Checkers)

لعبة داما (Drafts) تفاعلية مبنية بالكامل باستخدام تقنيات الويب الحديثة (HTML, CSS, JavaScript) مع واجهة مستخدم متجاوبة وعصرية باستخدام **Bootstrap 5**. تدعم اللعبة نمطين للعب: التحدي ضد الذكاء الاصطناعي (AI)، أو اللعب المباشر مع الأصدقاء أونلاين عبر غرف خاصة باستخدام **Socket.io**.

## ✨ المميزات (Features)

* **🎮 أنماط لعب متعددة:** 
  * اللعب الفردي ضد الذكاء الاصطناعي (AI).
  * اللعب الجماعي أونلاين في الوقت الفعلي (Real-time Multiplayer) عبر غرف خاصة.
* **📱 واجهة متجاوبة (Responsive Design):** تصميم متوافق تماماً مع جميع الشاشات (الهواتف المحمولة، الأجهزة اللوحية، والشاشات الكبيرة).
* **🎯 قوانين الداما العربية/التركية:** دعم الحركة المستقيمة (أفقي وعمودي) والأكل الإجباري وترقية القطع إلى "شيخ/ملك".
* **🎵 مؤثرات تفاعلية:** مؤثرات صوتية وبصرية عند تحريك القطع أو إعلان الفوز.
* **📊 نظام تسجيل النقاط:** عداد نقاط مباشر لتتبع عدد القطع المأكولة لكل لاعب.
* **🔗 نظام الغرف والمشاركة:** إمكانية إنشاء غرفة، نسخ الكود، أو مشاركته مباشرة عبر وسائل التواصل (Web Share API).
* **📖 صفحة القوانين المدمجة:** قسم خاص لشرح قوانين اللعبة دون الحاجة لمغادرة الصفحة (Single Page Application Approach).
* **🔍 صديق لمحركات البحث (SEO):** أكواد Meta و OpenGraph مضمنة.

## 🛠️ التقنيات المستخدمة (Tech Stack)

### الواجهة الأمامية (Front-end)
* HTML5 & CSS3
* JavaScript (Vanilla)
* [Bootstrap 5](https://getbootstrap.com/) - لتصميم الواجهة وتجاوب الشاشات.
* [Font Awesome](https://fontawesome.com/) - للأيقونات (أيقونات الملك، الأزرار، إلخ).
* [SweetAlert2](https://sweetalert2.github.io/) - لتنبيهات احترافية وجذابة.

### الواجهة الخلفية (Back-end)
* [Node.js](https://nodejs.org/) & [Express.js](https://expressjs.com/) - خادم الويب.
* [Socket.io](https://socket.io/) - للاتصال ثنائي الاتجاه في الوقت الفعلي بين اللاعبين.

## 🚀 كيفية التشغيل محلياً (Local Development)

### 1. تشغيل واجهة اللعبة
لا تحتاج واجهة اللعبة إلى خادم محلي لتعمل في وضع (الذكاء الاصطناعي). فقط قم بفتح ملف `index.html` في أي متصفح حديث وستبدأ اللعبة.

### 2. تشغيل سيرفر الأونلاين (لتفعيل اللعب الجماعي)
لكي يعمل وضع اللعب أونلاين، يجب تشغيل خادم Node.js محلياً:

1. تأكد من تثبيت [Node.js](https://nodejs.org/) على جهازك.
2. افتح سطر الأوامر (Terminal) داخل مجلد المشروع.
3. قم بتثبيت الاعتماديات المطلوبة بتشغيل الأمر:
   ```bash
   npm install express socket.io
   ```
